## ✨ What's Inside VibeHop v3.0

**VibeHop** is a pocket-sized, flow-state arcade runner crafted in a single vanilla HTML5 Canvas + Web Audio API file. Zero external dependencies, zero CDNs, and zero asset bloat—just synthesized lo-fi beats, glowing geometry, and forgiving rhythm-platforming.

- 🎵 **Beat-Synced Visuals, Sonar Ring & `+50 PERFECT` Timing (`VH-01`, `VH-10`)** — Horizon lines, neon pillars, jump rings, and a visual sonar ring around your avatar pulse in real time to the quarter-note beat so you can land `⚡ PERFECT VIBE` jumps even on mute.
- 🎹 **Dynamic Audio Stem Layering & Underwater Pause Muffle (`VH-02`, `VH-15`)** — Real-time Web Audio synthesizer sweeps its low-pass filter from `680Hz` (`1x`) to `2500Hz` (`8x`), layering snares, swing hi-hats, and a `5x+` fever arpeggiator, plus a warm `420Hz` master muffle on overlays/pause.
- 🔥 **Variable Jump Arc, Squash/Stretch & Near-Miss `GRAZE +25` (`VH-12`)** — Tap lightly for a crisp short-hop or hold for full height with elastic takeoff/landing deformation. Skimming the outer halo of a spike without losing a shield awards `🔥 GRAZE +25`.
- 🛤️ **Elevated Neon Synth-Rails (`VH-06`)** — Lock onto glowing upper rails after jumps to grind across hazards in a shower of amber sparks.
- 📼 **3-Goal Tape Deck Missions & Progression Unlocks (`VH-08`, `VH-11`)** — Complete *Alto's Odyssey*-style micro-goals to level up your persistent **Tape Rank (`TAPE LVL`)** and unlock new **Cassette Biomes** and **Avatar Geometries** (*Neon Cube*, *Vinyl Disc*, *Shuriken*, *Cyber Hex*).
- 📅 **Daily Seeded Run (`VH-13`) & Zen Flow Mode (`VH-05`)** — Compete on today's deterministic global obstacle course (`📅 DAILY SEED`) or toggle **`🧘 ZEN: ON (∞)`** for infinite shields and zero-stress cruising.
- 📤 **Generated PNG Cassette Share Card (`VH-14`) & Mobile HUD (`VH-03`, `VH-09`)** — Export a rendered `600×750` neon cassette scorecard PNG via Web Share API, complete with Android haptics, `🔊/🔇` Mute toggle, `⏸️` Pause, and auto-pause on tab/app switch.

## 🕹️ Controls

| Device | Action |
| :--- | :--- |
| **Mobile (Android / iOS)** | **Tap** = Low Hop • **Hold** = Full Jump / Auto-Hop • **Tap in Ring** = Dash • Top-Right `🔊`/`⏸️` |
| **Desktop** | **`Spacebar`** / **`↑ Up`** / **Click** = Jump or Dash • **`P` / `Esc`** = Pause • **`M`** = Mute |

## 📲 Install as an App (PWA)

1. Open **[https://bigknoxy.github.io/vibehop/](https://bigknoxy.github.io/vibehop/)** on your phone or desktop browser.
2. **Android / Desktop Chrome:** Tap the glowing **📲 Install App** button at the bottom of the screen.
3. **iOS Safari:** Tap **Share `[⎋]` → Add to Home Screen** for a full-screen, status-bar-free arcade experience.
